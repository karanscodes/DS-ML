# Introduction
Dictionary in python is a collection key-value pairs. <br>
Used to store data values like a map <br>
In some languages it is known as map or associative arrays.

```python
d = {
    'name': 'Karan',
    'age': 21,
    'gender': 'man',
}
```

## Characterstics
- mutable
- Indexing has no meaning
- Keys can't be duplicate
- Keys can't be mutable items

# Creating Dictionary
```python
# Empty Dictionary
d = {}

# 1D Homo Dictionary
d1 = {
    'name' : 'karan',
    'gender' : 'male',
}

# Mixed Dictionary
d = {
    'name' : 'karan',
    age : 21,
    'gender' : 'male',
}

# 2D dictionary
student = {
    'name' : 'Karan',
    'college' : 'LNCT',
    'sem' : 4,
    'subjects' : {
        'dsa' : 100,
        'math' : 67,
        'english' : 80,
    }
}
```
